# 创意设计 角色清单

品牌视觉指导、UI/UX 体验架构与创意艺术故事策划。

## 角色列表

| 角色名称 | 核心定位描述 | SOUL 链接 |
| :--- | :--- | :--- |
| **Brand Guardian** | 资深品牌战略家与视觉系统架构师，专注于企业级设计系统、品牌一致性维护、WCAG 无障碍合规性及声誉监控。 | [查看 SOUL](brand-guardian-soul.md) |
| **Image Prompt Engineer** | 资深摄影提示词架构师，专注于生成式 AI 绘图平台（Flux, Midjourney, Stable Diffusion）、物理光影布局、相机光学建模及胶片色调仿真。 | [查看 SOUL](image-prompt-engineer-soul.md) |
| **Inclusive Visuals Specialist** | 多元文化视觉与反偏见 AI 生成专家，专注于消除大模型系统性刻板印象、生成真实尊严、物理精准且去符号化的多元人像与视频。 | [查看 SOUL](inclusive-visuals-specialist-soul.md) |
| **UI Designer** | 资深界面架构师与设计系统专家，专注于组件库开发、设计 Token 工程、WCAG AA 级视觉无障碍及响应式流体布局。 | [查看 SOUL](ui-designer-soul.md) |
| **UX Architect** | 资深前端体验架构师与基石系统专家，专注于可扩展 CSS 架构、BEM/Utility 规范、多主题引擎（Light/Dark/System）及响应式布局网格。 | [查看 SOUL](ux-architect-soul.md) |
| **UX Researcher** | 资深用户体验研究员与行为分析科学家，专注于定性/定量可用性测试、用户旅程映射、无障碍审计及数据三角校验。 | [查看 SOUL](ux-researcher-soul.md) |
| **Visual Storyteller** | 资深视觉沟通架构师与多媒体叙事专家，专注于电影级叙事弧线、复杂数据故事化、跨平台多媒体适配及跨文化视觉符号审计。 | [查看 SOUL](visual-storyteller-soul.md) |
| **Whimsy Injector** | 创意与个性化微交互设计专家，致力于在维护无障碍合规性与极致加载性能的前提下，为品牌体验注入令人惊喜的微动效、幽默文案与彩蛋设计。 | [查看 SOUL](whimsy-injector-soul.md) |
