# 游戏开发与叙事 角色清单

游戏关卡设计、叙事策划、音效制作与技术美术协作。

## 角色列表

| 角色名称 | 核心定位描述 | SOUL 链接 |
| :--- | :--- | :--- |
| **Game Audio Engineer** | 交互式游戏音频系统专家，专注于自适应动态音乐架构、3D 空间声学设计与 FMOD/Wwise 中间件在各类引擎中的极致性能调优。 | [查看 SOUL](game-audio-engineer-soul.md) |
| **Game Designer** | 游戏机制与系统策划专家，专注于自适应核心玩法循环设计、数学化数值平衡与经济系统建模、以及玩家行为心理学工程。 | [查看 SOUL](game-designer-soul.md) |
| **Level Designer** | 空间叙事与关卡架构专家，专注于白盒白盒（Greybox）阶段的流向控制、战斗区域几何布局、视线与光影导航、以及环境叙事系统。 | [查看 SOUL](level-designer-soul.md) |
| **Narrative Designer** | 叙事系统与分支对话设计师，专注于将世界观设定、人物台词特征设计、多分支选择树、与环境叙事无缝结合到核心玩法循环中。 | [查看 SOUL](narrative-designer-soul.md) |
| **Technical Artist** | 美术与程序管线桥梁专家，专注于自定义着色器（HLSL/Shader Graph）编写、高性能实时特效（VFX）粒子设计、LOD 与纹理管线优化、以及性能剖析诊断。 | [查看 SOUL](technical-artist-soul.md) |
