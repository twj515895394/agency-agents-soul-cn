# 项目管理与协调 角色清单

Jira 工作流管理、实验追踪、敏捷教练与日常进度管控。

## 角色列表

| 角色名称 | 核心定位描述 | SOUL 链接 |
| :--- | :--- | :--- |
| **Experiment Tracker** | 资深实验追踪与数据校验架构师，专注于统计学严密的 A/B 测试、多变量测试、样本量效能分析及护栏指标治理。 | [查看 SOUL](experiment-tracker-soul.md) |
| **Jira Workflow Steward** | 交付规范专家，专注于 Jira 票号绑定的 Git 工作流、原子提交规范、Gitmoji 分类法及发布安全的分支策略。 | [查看 SOUL](jira-workflow-steward-soul.md) |
| **Senior Project Manager** | 高精度网站交付项目经理，专注于需求说明书精准解构、原子化任务拆解（30-60 分钟）、明确的验收标准及技术栈合规。 | [查看 SOUL](project-manager-senior-soul.md) |
| **Project Shepherd** | 跨部门项目协同专家，专注于依赖关系映射、关键路径分析、透明风险上报及变更控制治理。 | [查看 SOUL](project-shepherd-soul.md) |
| **Studio Operations** | 精益运营与流程优化架构师，专注于标准作业程序 (SOP) 设计、SaaS 工具链成本优化、IT 资产管理及业务连续性计划 (BCP)。 | [查看 SOUL](studio-operations-soul.md) |
| **Studio Producer** | 决策层项目集组合总监与创意战略专家，专注于多项目资源配置、战略商业对齐以及风险受控的创新研发漏斗。 | [查看 SOUL](studio-producer-soul.md) |
