## 🌟 项目愿景

传统的 AI 系统提示词（System Prompts）常常饱受**行为漂移**、**指令幻觉**以及**对抗性攻击（越狱）**的困扰。当提示词以宽松、叙事性的口吻编写时，大语言模型（LLM）很难在长上下文对话中始终如一地维持其规则边界。

**AI Agent 人格内核知识库 (soul.md)** 致力于通过“工程化规格”来解决上述问题。我们对原开源项目中的 **177 个专业级 AI Agent 角色** 进行了彻底的清洗、提炼与重构，将它们封装为基于 **八层认知架构** 的高刚性、高信息密度 `.md` 人格配置文件。每一个角色内核，都相当于一份确定性强、可预测、易于审计的 Agent 行为契约。

---

## 📐 8 层人格认知架构

本仓库中的每一个 Agent 人格内核（`-soul.md`）均严格且无条件地遵循以下统一的 8 维立体结构：

```
+-------------------------------------------------------------+
|  1. 身份 (Identity)   -- 标定核心视角与认知思维底盘         |
+-------------------------------------------------------------+
|  2. 核心真理 (Truths)  -- 冲突抉择时一锤定音的行动指南       |
+-------------------------------------------------------------+
|  3. 世界观 (Worldview) -- 对所属专业领域的稳定技术/商业信仰   |
+-------------------------------------------------------------+
|  4. 声音 (Voice)      -- 具体的排版格式规则与废话黑名单      |
+-------------------------------------------------------------+
|  5. 专业领域 (Domain)  -- 熟练掌握的技能清单与主动推诿声明   |
+-------------------------------------------------------------+
|  6. 边界 (Boundaries) -- 防御越权与防幻觉的强否定硬约束(不..) |
+-------------------------------------------------------------+
|  7. 记忆策略 (Memory)  -- 用户偏好与临时上下文的留存过滤规则   |
+-------------------------------------------------------------+
|  8. 痛点 (Pain Points)-- 锁死的禁用表达、禁用语气与反向人设   |
+-------------------------------------------------------------+
```

### 🛡️ 防御性“强否定边界”设计
本项目最具特色的是在 **Boundaries (强否定边界)** 层级引入的 **硬否定防御范式**：
* 中文版中的所有规则子项，**必须且只能以“不……”**语法开头。
* 英文版中的所有规则子项，**必须且只能以“Do not...”**语法开头。
* *安全价值*：该语法规范能从语义层面最大化大模型的防线关注度，彻底屏蔽正向建议混入安全边界，大幅削减大模型在长周期多任务场景下的“行为漂移”与“幻觉输出”。

## ⚡ 快速开始与工程化集成

您可以将本知识库中的任何 `soul.md` 文件极简集成到您的开发环境或 AI 代理框架中，一键赋予大模型极高品质的人格。

### 1. 在 Cursor / VSCode Cline 中使用
1. 打开对应目录，找到您想要赋予的角色内核（例如 `software-architect-soul.md`）。
2. 直接复制其内容，粘贴到您的 `.cursorrules` 文件中，或存放在 `.cline/prompts/` 下作为上下文约束。
3. 您的编辑器助手将立即以严密的系统架构师心智及防御边界投入到开发中。

### 2. 在 Claude Code 中集成
在命令行启动 Claude 时，将人格内核作为系统初始化参数传入：
```bash
claude --prompt "$(cat specialized-mcp-builder-soul.md)"
```

### 3. 在主流多智能体框架（LangChain, CrewAI, AutoGen）中集成
In 初始化 AI 执行体时，将 `soul.md` 文件正文作为系统提示词（System Message）注入：
```python
from crewai import Agent

# 加载高刚性中文角色内核
system_soul = open("software-architect-soul.md", "r", encoding="utf-8").read()

architect_agent = Agent(
    role="系统架构师",
    goal="设计工业级高可用分布式系统蓝图",
    backstory=system_soul, # 注入 8 层架构与防御边界
    verbose=True
)
```

## 🇺🇸 双子仓库对齐机制 (Bilingual Twin)

本项目与英文仓库 **[agency-agents-soul](https://github.com/twj515895394/agency-agents-soul)** 保持 **100% 同名同配**：
* **文件名完全一致**：无论在中文库的哪个序号文件夹下，其角色内核文件名均与英文库一字不差（如 `/marketing/seo-specialist-soul.md` 对应本仓库的 `/08_增长与数字营销/seo-specialist-soul.md`），确保各类开发工具、同步脚本能无摩擦批量读取。
* **双语精细互查**：本中文仓库中的所有配置文件均经过深度的本地化翻译与工程化清洗，将一切模糊营销词转换为具备可落地、强工业背景的中文商务/工程语境。
